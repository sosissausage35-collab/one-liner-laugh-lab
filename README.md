A Node program that writes one short funny line answering a prompt — the excuse a robot vacuum gives after eating a sock — to `/output/entry.txt`. It scores several fresh candidate lines on the judge's criteria in order (funny, then original, then how well the line fits the prompt, then how tight the wording is) and picks the winner by lexicographic comparison, not a weighted sum.

## Run it

```sh
node main.ts
```
